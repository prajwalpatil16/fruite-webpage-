## 🧩 Problem & Solution

### The Challenge
Local fruit vendors and small grocery businesses lack the digital infrastructure to compete with large quick-commerce apps, losing customers who prefer online convenience and transparent pricing.

### Our Solution
**Fruite** provides a robust, full-stack storefront that empowers local vendors with:
- ✅ **Secure Authentication** for personalized customer experiences.
- ✅ **Dynamic Inventory Management** for real-time stock updates.
- ✅ **Persistent Cart & Checkout** system for seamless transactions.
- ✅ **Order Management Dashboard** for tracking and fulfillment.

---

## ✨ Features

| Feature | Description |
|---|---|
| 🔐 **Authentication** | JWT-based secure login, registration, and profile management |
| 🛍️ **Product Catalog** | Categorized product listings with variants and stock tracking |
| 🛒 **Persistent Cart** | User-specific cart saved across sessions |
| 💳 **Secure Payments** | Integration with Razorpay/Stripe (planned) and COD |
| 📦 **Order Tracking** | Real-time order status updates from placement to delivery |
| 📊 **Admin Dashboard** | Comprehensive tool for managing products, orders, and sales |
| 📱 **Responsive Design** | Optimized for all devices using React and modern CSS |

## 🛠️ Tech Stack

### Frontend
- **React.js** with **Vite** for a fast, modern UI.
- **Vanilla CSS** for premium, custom-tailored designs.
- **Context API** for state management.

### Backend
- **Python Flask** for a lightweight, scalable API.
- **MySQL** for robust relational data management.
- **Flask-SQLAlchemy** as the ORM.
- **JWT** for secure, stateless authentication.

## 🚀 Getting Started

### Prerequisites
- Python 3.9+
- Node.js & npm
- MySQL Server

### Backend Setup
1. Navigate to `/backend`.
2. Install dependencies: `pip install -r requirements.txt`.
3. Configure your `.env` file with MySQL credentials.
4. Run the server: `python app.py`.

### Frontend Setup
1. Navigate to `/frontend`.
2. Install dependencies: `npm install`.
3. Start the dev server: `npm run dev`.
